# v2.2.0

## 不具合報告・Q&A

- 配色を落ち着いたスレートグレーと青に変更し、左側のカテゴリと横長1列の投稿一覧で探しやすくしました。
- 投稿の間隔と境界線をはっきりさせ、タイトル・本文の抜粋・対応状況・返信数を読み取りやすくしました。
- 検索と投稿ボタンをまとめ、詳細・投稿フォームの配色も統一しました。スマートフォンでは画面幅に合わせて配置を調整します。
- 投稿・本人編集・画像添付・認証・管理者操作・定期更新の機能は引き続き利用できます。

## 蔵書の件数と整理後の表示

- 蔵書情報の更新時に整理済み・未整理・両方の件数も更新し、スクロール位置を保っている間も古い件数が残らないようにしました。
- 旧DBの巻数を補正した最初のページでも、カードと合計のファイル数が一致するようにしました。
- 整理完了直後は保存先の蔵書登録を自動で待って巻一覧を開きます。更新に時間がかかる場合は準備中と表示します。

## リンク取得

- ダウンロード・整理状況に実進捗率のプログレスバーを追加しました。進捗取得前は確認中、整理中は処理中、整理完了はチェック付きで表示し、確認待ち・未取得巻がある場合も区別します。

- 全巻・欠巻・指定巻取得のボタンに押し込みの反応と「選択中」の表示を追加しました。取得方法を切り替えると表示も切り替わり、巻指定や作品を変更すると解除されます。

- チャコールと落ち着いた青を基調に、上部の横並びナビから検索・欠番確認・未整理の整理・登録状況などへ切り替えられるようにしました。
- 左に作品一覧、右に表紙・掲載巻・所持巻と取得操作を配置し、右側の入れ子スクロールをなくしました。「対象ページを表示」も利用できます。
- 所持済みは青緑、未所持は琥珀色で表示し、取得する巻はチェックで選べます。
- 全巻取得・欠巻取得ボタンの下に対象の巻数を表示し、その下に指定巻取得を配置しました。
- 登録確認を状況欄の後に配置し、ダウンロード・整理状況が指定巻取得の直下に表示されるようにしました。状況は最初に2件を表示し、続きは状況欄内で確認できます。各行を開くと詳細と既存の操作を利用できます。
- スマートフォンでは上下に配置し、接続設定・登録確認・未整理の整理・欠番確認など既存機能を維持しました。

- 欠番調査中の定期更新で別のタブから欠番画面へ戻される不具合を修正しました。メニューでは保存済みの結果・進捗を表示し、再調査は画面内の調査ボタンから開始します。

## スマホ・タブレットからの接続

- ランチャーの右クリックに「同じLANからの接続を許可（管理者）」を追加しました。有線LAN・Wi-FiのIPとサブネットから接続元の範囲を自動判定し、現在のランチャーと使用TCPポートへの接続だけを許可します。
- 対象はWindowsでプライベートに設定されたLANです。VPN・仮想アダプターや他の通信ルールは変更せず、ルーター・接続先・ポート変更後に再実行すると、この機能で作った許可を現在の環境へ更新します。実行時はWindowsの管理者確認が表示されます。

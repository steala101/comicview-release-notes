# v2.3.1

## 漫画の整理

- まとめて選んだ作品の整理を並行して進めます。作者や巻番号の回答を待つ間も、ほかの作品の準備・圧縮を続けます。同じ作品の続巻と、蔵書への反映は順に処理します。
- PCの整理ツールで作品ごとの進捗と確認待ちを一覧に表示します。複数作品の作者情報をそれぞれのカードで入力し、確定した作品から整理に戻れます。
- ComicViewの整理画面に作品別タブを追加しました。タブを切り替えて進捗・確認・ログを見られ、入力途中の内容を保持します。
- ComicViewでは「この内容で確定」の後、次に確認待ちの作品タブへ自動で移ります。同じ作品の別巻は1つのタブにまとめ、フォルダごとの状況をその中に表示します。

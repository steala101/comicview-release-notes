# ComicView v2.1.5



## ジャンル分類



- ローカルLLMの参考情報が空のときに、題名が一致する作品のジャンル・あらすじを補完します。短い題名の印象だけで日常系やコメディに決めてしまう誤分類を減らします。

- 異世界・ファンタジー・SFの根拠がある作品では、付随するコメディ要素より主題を優先するようにしました。超能力や魔法の補助タグだけでギャグ作品を変更しないようにしています。

- 別作品の検索結果を参考にしない題名照合と、参考情報のキャッシュ・通信失敗時の待機抑制を追加しました。手動ジャンル設定とotherフォルダの成人向けルールは維持します。



## 非公開リポジトリからの更新



- 非公開のcomicview-updates向け配布は、登録済みの更新キーをランチャー内部へ組み込む方式を継続します。キー入り配布物の公開リポジトリへの添付防止と、ビルド時のキー照合も維持します。

- 配布前のEXE自己検査で、結果ファイルを保存できず検査用ダイアログが残る問題を修正しました。検査ごとの一時ファイルを使い、利用者データと分離して確認します。

- 手渡し用のcomicview-update.zipを通常の更新配布・GitHub添付の対象から外しました。以後は部品別の更新ファイルを使用します。

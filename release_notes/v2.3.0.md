# v2.3.0

## ダウンロード・整理

- 進捗欄の「要確認」から対象作品を絞り込めます。保存先や巻番号の回答が必要なときは、そのまま確認画面を開けます。
- ダウンロード完了と整理の進行を分けて表示し、書庫の解凍・確認、保存した巻の数、蔵書への反映が分かるようにしました。

- 共有フォルダーからサブPCの書庫準備用ウィンドウを起動すると、メインPCで複数タイトルを整理している間に、後続タイトルのZIP・CBZ・RAR・CBR書庫をサブPCで先に準備できます。完成版の保存、蔵書更新、元フォルダーの後片付けはメインPCで行います。
- PCの整理ツールでも、登録済みの続巻を確実に照合できる場合は保存先を自動で選びます。雑誌まとめの提案は5秒後に適用します。

## リンク取得

- 整理済み・未整理・未所持を巻ごとに表示します。対応する蔵書を選び直すと、所持巻と取得チェックを更新します。

## 漫画ライブラリ・読書

- ホームに最近追加された未読巻を表示し、既存作品の続巻もその場から読めます。
- 蔵書の検索・ジャンル・整理状態・読書状況・完結条件・並び順を名前を付けて保存できます。巻一覧を閉じると、条件と一覧位置に戻ります。

# v2.2.1

## リンク取得

- 「整理状況」を開くとサイトの作品一覧が表示される不具合を修正しました。整理状況を専用の一覧で表示し、開いた時に最新の進捗を取得します。作品一覧へ戻ると巻選択とその下の状況欄を再表示します。

## 接続先の切り替え

- 漫画ライブラリにLAN／Tailscaleの接続切り替えボタンを追加しました。同じPCに接続できることを確認してから移動し、LANへ届かない場合はTailscale接続を継続します。
- LAN利用中に通信が途切れた場合はTailscale側へ自動で戻ります。Bluetoothはネットワーク接続としてPCへ通信できる場合に利用できます。接続確認時は一時的な小窓を開き、プロフィールと基本表示設定を引き継ぎます。保存済みの本は接続先ごとのブラウザー保管庫に残ります。

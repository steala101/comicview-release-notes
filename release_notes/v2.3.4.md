# v2.3.4

## 漫画ライブラリの表紙

- 作品表紙に使っていた巻を削除すると、残っている巻から作品表紙を自動で作り直します。
- 先頭に大きな白い余白付きでカバー全体が印刷されている場合、直後に同じ絵柄の単ページ表紙があれば、そのページをサムネイルに使います。
- 従来のサムネイルキャッシュを再利用し、余白付きカバーの旧サムネイルだけを作り直します。
- アプリの裏で表紙を保存する機能が使えない接続でも、表示した表紙を端末に保存し、サムネキャッシュの件数と先読み確認に反映します。
- アップデート時に端末の表紙キャッシュを消さず、以前と同じ表紙データを引き継ぎます。先読みでも端末に残っている画像を優先して使います。
- サムネキャッシュで、端末の保存庫とPC側の生成済み枚数を分けて表示します。確認ボタンでは先頭の作品表紙を対象に、ブラウザーの画像キャッシュも調べます。
- サムネキャッシュからPC側の保存先を開けます。先読み結果には端末に追加した件数を表示します。
- 蔵書では、次に見える行の表紙を画面に入る前に読み込み、表示準備を済ませます。

## リンク取得

- 「整理済みフォルダから選ぶ」「未整理フォルダから選ぶ」は入力に合わせて更新します。「闇落ち」と「闇堕ち」などの表記ゆれも照合します。
- 「ダウンロード・整理状況」から、整理の開始や再開が可能なダウンロード済みの作品をまとめて待ち列に追加できます。
- サイトの作品と対応する整理済み・未整理フォルダーを手動で選べます。未整理から整理を完了すると、保存した対応を整理先へ引き継ぎます。
- 副題の違いで一致しない場合は、主題が同じで表記が近い一意の候補の所持巻を、別作品の可能性を示して表示します。候補を絞れない場合は「対応する所持作品を見直す」から選べます。
- 登録済みで取得中の作品は、サイトの作品一覧に「ダウンロード中」と表示します。所持巻数が取得可能巻数より多い場合は作品詳細に警告を表示します。
- 自動登録をオンにすると、選択したまとめ巻と別リンクの巻の重複だけであれば、注意を表示してリンクグラバーへの登録を進めます。
- 設定から作業・確認待ちコピーとバックアップの容量を確認できます。蔵書への保存を照合できた作業コピーは、確認してから削除できます。
- 表示を消した終了済み・取り消し済み履歴の作業コピーも、クリーンナップから削除できます。履歴をクリアするときに終了済みコピーもまとめて片付けられます。
- 「接続・保存先設定」は、画面の外側をクリックして閉じられます。

## 漫画の整理

- 既存作品に合流する際、句読点などの表記ゆれがあっても同じ作品・作者・巻・版の書庫は既存名で上書きし、旧書庫は退避します。追加巻と作品フォルダーにも既存の表記を使います。
- 既存作品へ整理するときも雑誌版の表示を保ちます。通常版が全巻分ある雑誌書庫と、画像が同じ通常版の重複を蔵書フォルダーから退避します。
- まとめ書庫に範囲内の巻がすべて個別に入っている場合、同じ階層に紛れた単話フォルダーを表紙確認と整理から外します。元の書庫は、残す各巻の画像が作成ZIPと一致したときに整理します。
- 出版社レーベル付きの巻名と雑誌版の個別巻にも、まとめ書庫の巻別照合を適用します。
- 整理で新しく作るフォルダー・書庫やリンク取得の保存名では、ダッシュなどの記号を半角に揃え、感嘆符は「！」に揃えます。
- 確認用の準備ができたダウンロード作品を先に整理へ渡し、確認・整理中の画面にも別作品のタブを順次追加します。
- 巻名の末尾に出版社レーベルが付いた複数巻書庫を、巻ごとに分けて整理します。
- まとめて整理中は、画面左上に選択中の作品タブのタイトルを表示します。
- 複数巻入りの書庫を巻ごとに照合します。上書き前後の作成ZIPに候補がある場合は、元の画像が各巻の一つの候補に揃っていれば元書庫を整理し、一致しない巻があれば元書庫を保持します。

# v2.3.2

## PC版の整理ツール

- 並行整理で作品が確認待ちになると、「処理」画面で確認内容を自動表示します。漫画情報は入力カードに並び、保存先や巻数などの確認も順に開きます。
- 実行モードを単体処理に統一しました。複数のタイトルフォルダをまとめてドラッグ＆ドロップすると並行整理できます。
- 処理が完了したら対象フォルダの選択をリセットします。保存先と処理結果は残ります。
- PC版でも未整理の作品を1つ選ぶだけで、蔵書に登録されている同じ作品の別巻を候補に加え、巻数の若い順に同じ保存先へまとめて整理します。
- 保存先の画面を作品単位にまとめました。整理する巻と現在の保存先を並べて表示し、既存作品やかな行をボタンで指定できます。作品ごとの枠と間隔を広げ、自動判定のかな行候補を大きく表示します。
- 同じ作品としてまとまったフォルダを1つずつ選択できます。チェックを外したフォルダは今回の整理と保存先の一括指定から外れ、元のフォルダに残ります。
- 漫画情報の確認で、候補と表紙の読み取り結果を合わせた際に同じ人が原作者・作者の両欄に入らないようにしました。
- 自動判定のかな行候補を「このかな行に保存」で実行前に確定できるようにしました。指定したかな行を使うため、処理中に似た作品とのマージを確認する画面が出ません。

# v2.3.5

## リンク取得

- 作品詳細に「対応する所持作品を見直す」を常に表示します。自動照合で所持済みになった場合も、主題が同じ別の作品を候補から選べます。見つからなければ、下の整理済み・未整理フォルダから検索できます。
- PC幅では、作品一覧と右側の操作欄をマウスの位置に応じて個別にスクロールできます。
- サイトに主題だけが載り、蔵書では空白の後に副題が続く場合も、候補が一つに絞れれば所持済みと表示します。
- JD2の解凍が待機中の場合は一覧からの削除も待ち、解凍完了を確認してから整理済みのリンクだけを取り除きます。削除直前に待機に変わった場合も再確認します。

## 蔵書

- 表紙を開いたら巻一覧を先に表示し、表紙の個別設定はあとから反映します。別作品の読書記録も巻一覧の計算から外し、クリック後の待ち時間を短くします。
- スクロールで表示範囲が移ったときは、遠い行の先読みより、いま表示される表紙の読み込みを優先します。表示範囲に近い表紙の先読みとデコードは続けます。

## 作品名の変更

- 別の処理がファイルを短時間開いているときは、作品フォルダの移動を再試行します。ロックが続く場合は元の作品を保ち、理由を表示します。

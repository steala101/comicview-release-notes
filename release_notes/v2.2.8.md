# v2.2.8

## 漫画ライブラリ・読書

- 巻が見つかった作品では、同じフォルダの存在確認を繰り返さないようにしました。

- 変更のない書庫フォルダを開き直すときは巻一覧を再利用し、ファイルサイズの確認は表示後に行います。

- 巻サムネイルの更新確認を巻一覧の表示後に移し、表紙設定の重複読み込みを減らしました。

- 巻一覧で、登録先と完全に同じパスを重複して解決する処理を省きました。

- 巻一覧の初回表示で確認済みの蔵書索引を使い、変更のないお気に入り台帳の読み直しも省きました。

- 巻一覧を開くときは、フォルダを列挙した際のファイル情報を使い、巻ごとの再問い合わせを減らしました。

- 蔵書をスクロールして表紙を読み込んでいる間も、巻一覧を要求できるよう表紙の同時通信数を抑えました。巻一覧の通信に時間がかかった回は内訳を診断ログに記録します。

- 作品を開いたときの続巻照合で、蔵書が変わるまで照合索引を使い回し、その作品の候補だけを確認するようにしました。

- 同じ作品をすぐに開き直したときは、前回の巻一覧を先に表示し、最新情報の確認が取れたら操作できるようにします。変更のない読書台帳は解析済みのデータを再利用します。

- 作品を開く際は確定済みの読書記録を一度だけ読み込み、他の設定の保存を待たずに巻一覧を表示します。

- 新刊・本棚の情報を起動時に読み込み、巻一覧と同時に表示します。初めて開く作品の新着記録は、巻一覧を表示できる状態になってから保存します。

- 取得済みのあらすじを起動時に読み込み、作品を開くと巻一覧と一緒に表示します。台帳の更新内容は後から反映します。

- 作品を開くと巻一覧を先に表示し、あらすじ・新刊・本棚の情報は後から読み込みます。蔵書の登録先に変更がない間は、アクセス確認に前回の登録索引を使います。

- 蔵書全体の表示データを用意している間も、作品の巻一覧を開く処理を進められるようにしました。

- 似た作品の検索は、巻一覧の下部までスクロールするか「似た作品を表示」を押した時に始めます。作品を続けて開くときの待ち時間を抑えます。

- 巻一覧の表示に時間がかかった場合、どの処理で待ったかをサーバーの診断ログに記録します。

- 画像が直接入っている解凍済みの巻は、フォルダに変更がなければ前回の判定を再利用し、巻一覧を開き直す際のディスク読み込みを減らしました。

- お気に入りやジャンルの更新時に蔏書の作品索引を再利用し、巻一覧の表示が更新処理で待たされる時間を短縮しました。

- 作品の巻一覧を表示してから、画面に近い巻のサムネイルを少しずつ取得します。未生成の巻の表紙が多い場合も、まとめて生成を始めないようにしました。

- 作品の開閉を繰り返すとき、容量計算や関連作品の読み込みが次の巻一覧と重ならないようにしました。容量は保存パネルを開いたときに取得します。

- 初めて開く作品でも、解凍済みの巻フォルダを効率よく確認して巻一覧を表示します。

- 蔵書で作品や「続きから読む」を開くときは、一覧の表紙や先読みより巻一覧・読書の読み込みを優先します。
- 直下に書庫がある作品の巻一覧を再利用し、巻の追加・移動があれば取り直します。

- 変更のない巻ファイル一覧はアプリを再起動しても再利用します。確認済みの一覧がない作品は裏で順に調べ、サムネイルを開くたびにフォルダを列挙する待ち時間を減らします。

- 自動整理の監視やダウンロード進捗の取得が登録履歴を何度も一括で読み直す処理を見直し、履歴が多い場合に巻一覧などの応答が止まる時間を減らしました。

- 巻一覧を開くとき、登録済み作品のフォルダ情報を移動確認と巻一覧で共用し、同じ場所に繰り返し問い合わせる待ち時間を減らしました。

- 続巻通知で読書カタログの解析結果を再利用し、読書記録とは別に処理するようにしました。変更がないカタログの書き直しと、巻一覧を開く際の表紙設定の重複読み込みも減らしました。

- 巻一覧を開く際、Windowsでは蔵書台帳の更新を軽いファイル属性照会で確認し、登録状況の確認にかかる待ち時間を減らしました。

- Windowsのローカル保存先では、蔵書台帳とお気に入りの変更通知を使い、変更のない作品を開く際のディスク照会を省くようにしました。

- 続巻通知の取得時に蔵書の登録情報を巻ごとに確認し直す処理と、ダウンロードの自動再開時に登録履歴を全件展開する処理を省き、巻一覧と並行したときの待ち時間を減らしました。監視を張り直しただけの場合は、同じ台帳を再解析しません。

- 巻一覧を開く際、表紙・作品の表示名・タグ・読書記録は変更がある時に読み直し、変更のない設定へのディスク照会を減らしました。

- 同じ名前の書庫を差し替えた後、古い本文や先読み画像が残る問題を修正しました。巻を開くたびに書庫の版を確認し、本文・加工画像のキャッシュを分けます。

## 漫画の整理

- 構造判定で雑誌まとめが提案されたときは、5秒間回答がなければ提案どおりに整理を続けます。保留分の確認画面でも同じように進みます。
